# UpBeatX - Responsive Landing Page

A modern and responsive landing page built using HTML, CSS, and JavaScript for a lead generation and growth-focused company.

## Features

- Responsive design
- Fixed navigation bar
- Smooth scrolling
- Scroll fade-in animations
- Interactive FAQ section
- Modern UI design
- Hover effects and transitions
- Fully responsive layout

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Goal

This project was created as part of a Web Development Virtual Internship to improve frontend development skills and build modern responsive web interfaces.

## Sections Included

- Hero Section
- About Section
- Statistics Section
- FAQ Section
- Contact/Footer Section

## What I Learned

- Responsive web design
- Flexbox layouts
- Smooth scrolling effects
- Scroll reveal animations
- UI spacing and visual hierarchy
- Interactive website components
